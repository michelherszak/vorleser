# Technische Dokumentation

- [Architecture](Architecture/README.md): Aufbau der Anwendung, Datenfluss, Quellcode-Zuordnung und Findings zum vorhandenen Stand.
- [ADR](ADR/README.md): einzelne Architekturentscheidungen mit Kontext, Konsequenzen und offenen Fragen.

Die Dokumentation beschreibt den Quellcode und die anschließenden Verbesserungen vom 16.10.2026. ADR 0001 bis 0003 rekonstruieren vorhandene Entscheidungen und belegen keine gesonderte Architekturfreigabe; ADR 0004 dokumentiert die beauftragte Weiterentwicklung. Der Prüfstand steht in der Architekturübersicht. Die Verfügbarkeit und Unterstützung der Anfrageparameter durch die produktive externe API wurden nicht geprüft.
